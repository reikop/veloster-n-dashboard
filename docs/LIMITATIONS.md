# 지원 범위와 한계

## 호환성과 검증

확인한 내비게이션은 product `jsn_kr`, device `daudioplus_jsn_kr`, hardware `tcc893x`, API 17, incremental `eng.vmadmin.20250902.081552`입니다. 차량 연식이나 Android 버전만으로 같은 프레임워크라고 판단하지 않습니다.

v5 `HscanDataClient`는 **product와 incremental이 위 값과 정확히 일치할 때만** 소켓에 연결합니다. 다운로드본 260114와 실차 250902를 같은 펌웨어로 간주하지 않습니다. 다른 모델에 적용하려면 인터페이스·수신 형식·권한을 별도로 검증해야 합니다.

2026-10-22에 일반 앱 UID로 v5 설치·실행, 흡기온·배터리 전압/SOC·조향속도·TCS/ESC/ABS 비작동 표시와 기존 순정 연결 유지를 확인했습니다. 이것은 실제 ABS/TCS/ESC 작동 전환, 외부 계측과의 정확도, 장시간 운행, 냉간 재부팅, 실차 pause/resume까지 검증했다는 뜻이 아닙니다. v3와 ‘내 앱’ v8은 이전 설치 확인본입니다. 이전 ‘내 앱’ v9는 서명·호스트 검사를 마친 사전 배포이며 실차·에뮬레이터 실행은 미검증입니다. v8의 설치 이력을 v9 바로가기의 실차 성공 근거로 확대하지 않습니다.

## 데이터 의미

| 항목 | 해석 및 한계 |
| --- | --- |
| 기본 계기판 | 기존 NMode/Vehicle/BCM/PGS 수신 인터페이스 이용. ECU에 진단 요청을 새로 보내지 않음 |
| 추가 차량 값 | `hscan_mux` abstract socket에 추가 수신자로 연결. function 07/23/53/5a/6e 및 정확한 길이만 해석 |
| TPMS | 4개 공기압을 한 카드에 psi로 표시. 타이어 온도 아님 |
| 출력·토크·부스트 | 일부는 환산·계산 표시이며 별도 계측기 정확도 보장 없음 |
| 변속 알림 | 기본 6,000 RPM, 조절 가능. 모든 기어·튜닝 상태에 대한 최적 변속 맵 아님 |
| TCS/ESC/ABS | 상태 비트 표시. 수신값 0 확인과 실제 개입 시 1 전환 검증은 구분 |
| 배기온·e-LSD | 수신/의미 확정 실패. 미확인 숫자를 온도·작동률·전류로 표시하지 않음 |
| 미디어 | OEM이 보내는 재생 정보에 의존. 소스별 제목·아트워크·진행률·제어 제공 여부가 다를 수 있음 |

**마지막 수신 후 60초**가 지나면 값이 `-`가 됩니다. 같은 숫자를 새로 수신하면 유효 시간이 갱신되므로 ‘숫자가 1분간 안 변하면 무조건 만료’와는 다릅니다. MICOM이 이전 센서 값을 계속 전송할 경우 센서 자체가 새로 측정했는지까지 알아낼 수 없습니다.

264바이트 프레임의 고정 헤더·XOR·C7 항목 개수/길이/패딩을 검증합니다. 읽기와 해석 스레드를 분리하고 큐를 32×최대 4,096바이트로 제한하며, 넘치면 오래된 청크와 단절된 프레임 조각을 버립니다. 무손실 전체 CAN 기록기가 아니며, 내비에 전달되지 않는 ECU 값까지 얻을 수 없습니다.

소켓 구현은 송신 스트림, ECU 요청, OEM 통신 초기화 호출을 사용하지 않습니다. 기존 OEM 서비스가 송출하는 범위에 의존하므로, 수신이 없다고 모든 ECU에 해당 정보가 없다는 뜻은 아닙니다. 연결 자체의 자원 사용과 장시간 영향은 별도 확인해야 합니다.

## 기기 기능

- v9 [실행 바로가기](QUICK_ENTRY_ko.md)는 표준 Android 오버레이·알림·서비스이며 기본값은 OFF입니다. 사용자가 켠 경우에만 부팅 후 작은 바로가기 복원을 요청합니다. 계기판·내 앱 화면 자체를 자동으로 열지 않습니다.
- 표준 방식으로 설계했다는 것과 모든 기기에서 표시·접근 가능하다는 것은 다릅니다. 오버레이가 거부되면 알림을 유지하지만 순정 UI가 알림도 숨길 수 있습니다. 강제 종료·기기 정책·권한이 복원을 막을 수 있으며 화면 터치와 정상 재부팅 확인이 필요합니다.
- 새 설치 도구는 지원 빌드를 확인합니다. v9 바로가기의 범용 구조가 차량 데이터 호환성이나 설치 허용 범위를 넓히지는 않습니다. [OEM 메뉴 수정](MENU_ENTRY_ko.md)은 선택형 대안으로 별도 원본 APK·ODEX 일치를 요구합니다.

- 독립 앱은 순정 N 모드에 넣었던 버튼이 사라지는 문제를 피하기 위한 구성입니다. 순정 버튼 자체의 원인을 수정하는 패치는 아닙니다.
- ‘내 앱’의 USB 버튼은 OEM USB 모드를 요청하고, 재시작은 `REBOOT` 권한을 사용합니다. 기기 정책에 따라 거절될 수 있습니다. Bluetooth 검색/페어링도 선택한 동작에 따라 상태를 변경합니다.
- ‘내 앱’에는 **연결 점검/시험 핫스팟** 화면과 Wi-Fi·네트워크 권한이 남아 있습니다. 확인창을 거쳐 시험하며 무선 CarPlay가 구현된 것은 아닙니다. 대상 기기에서는 Wi-Fi 활성화가 실패했습니다. 이것만으로 Wi-Fi 하드웨어가 물리적으로 없다고 확정하지는 않습니다.
- 일반 Bluetooth 페어링 화면이 XGPS160의 10Hz GPS를 계기판에 연결해 주지는 않습니다. GPS 트랙 랩타이머와 최신 N 앱 이식은 구현하지 않았습니다.
- 자동 업데이트·인터넷 배포 서버·OTA 기능은 없습니다. APK를 수동 업데이트합니다.
- 앱은 API 17 대상이며 `debuggable=true`인 연구 배포본입니다. 범용 최신 Android 앱과 동일한 배포·보안 수준을 주장하지 않습니다.

## SD·서명·권한

ZIP 암호로 펌웨어를 풀 수 있다는 것과 수정 OTA를 서명할 수 있다는 것은 다릅니다. 다시 압축해도 OEM recovery의 서명 검증을 통과하는 근거가 되지 않습니다. SD 카드에 APK를 놓기만 해 설치되는 경로도 확인하지 못했습니다.

배포 APK는 Android 4.2 호환 V1/JAR 서명입니다. 공개 AOSP 테스트 인증서는 OTA 비밀키가 아니고, 임의의 개인 인증서로 다시 서명한 앱이 대상 차량에 설치된다고 보장할 수 없습니다. 일반 로컬 테스트 서명으로 만든 ‘내 앱’은 대상 차량에서 거절된 이력이 있습니다. APK 서명 방식과 업데이트 시 서명 일치는 [AOSP 앱 서명 설명](https://source.android.com/docs/security/features/apksigning)을 참고하세요.

순정 펌웨어·프레임워크·홈 APK·서명 개인키를 이 공개 패키지에 추가해서는 안 됩니다. 공개 폴더만으로 OEM 시스템이나 OTA를 재빌드할 수는 없습니다.

현재 다국어 배포는 N 계기판 v6·내 앱 v10입니다. 두 앱 모두 호스트·서명 검사만 완료했고 새 버전의 실차·에뮬레이터 시험은 하지 않았습니다. 차량 데이터 처리와 기본 지원 빌드는 그대로이며, 언어 선택이 해외 사양 호환성을 추가하지 않습니다. [언어 안내](LANGUAGES.md).
