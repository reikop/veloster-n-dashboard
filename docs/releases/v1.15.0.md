N 계기판·'내 앱'·모든 설치기 **1.15.0**. **USB 메모리로 업데이트**할 수 있게 됐습니다.

| 기기 | 받을 파일 | 사용 |
| --- | --- | --- |
| Windows | `vn-installer-windows.zip` | 압축을 풀고 `N계기판설치.cmd` 더블클릭 → 창에서 [설치] (이전 창 설치기는 [업데이트] 단추가 뜹니다) |
| 맥 | `vn-installer-mac.zip` | 압축을 풀고 `N 계기판 설치.app` 실행 |
| 안드로이드 폰·태블릿 | `vn-installer-android.apk` | 설치 후 OTG 어댑터(USB-C → USB-A 암) + A-A 케이블로 차에 연결 |
| 리눅스 | `vn-installer-linux.zip` | `bash install.sh` |
| **USB 메모리** | `vn-usb-update.zip` | 압축을 풀어 `vn-update` 폴더를 USB 메모리 맨 위에 넣고 차에 꽂기 → [설치] ([USB 업데이트](https://github.com/reikop/veloster-n-dashboard/blob/main/docs/USB_UPDATE.md)) |

바뀐 점
- **USB 업데이트**: USB 메모리를 꽂으면 '내 앱'이 새 버전을 알려 주고, [설치]를 누르면 계기판과 '내 앱'을 바꿉니다. 창이 안 뜨면 '내 앱' → USB 업데이트를 누르세요.
  - **1.15.0 자체는 기존 설치기로 한 번 설치해야 합니다.** 그다음 버전부터 USB로 업데이트됩니다(1.15.0을 USB로 받으려면 이 기능이 이미 있어야 하기 때문).
  - 안전장치: USB의 목록 파일은 별도 업데이트 키로 서명되어 있고, '내 앱'이 그 서명과 각 APK의 크기·SHA-256·서명자·패키지·버전을 모두 확인한 뒤에만 설치합니다. 벨로스터 N 헤드유닛용이고 설치된 것보다 새 버전일 때만, 화면에서 [설치]를 눌렀을 때만 설치합니다.

확인 범위
- 확인: 호스트 시험(번들 생성·서명·변조 거부 포함 35개 프로그램), 안드로이드 에뮬레이터에서 USB 장착 → 창 → 설치 화면 없이 두 앱 교체 → 완료 알림.
- 미확인: 벨로스터 N 실차에서 USB를 꽂았을 때 창이 뜨는지(안 뜨면 '내 앱' → USB 업데이트), 설치 권한이 주어지는지(안 되면 순정 설치 화면이 앱마다 한 번 열림). 이상하면 알려 주세요.
