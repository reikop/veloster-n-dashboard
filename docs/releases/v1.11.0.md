버전 이름을 하나로 통일했습니다. 이번부터 N 계기판, '내 앱', 모든 설치기가 같은 버전 **1.11.0**을 씁니다(이전 이름: 계기판 v25 `1.24-ncustom-purple`, 내 앱 v11 `1.10-star`, 설치기 `2026-11-24`).

| 기기 | 받을 파일 | 사용 |
| --- | --- | --- |
| Windows | `vn-installer-windows.zip` | 압축을 풀고 `N계기판설치.cmd` 더블클릭 → 창에서 [설치] |
| 맥 | `vn-installer-mac.zip` | 압축을 풀고 `N 계기판 설치.app` 실행 |
| 안드로이드 폰·태블릿 | `vn-installer-android.apk` | 설치 후 OTG 어댑터(USB-C → USB-A 암) + A-A 케이블로 차에 연결 |
| 리눅스 | `vn-installer-linux.zip` | `bash install.sh` |

바뀐 점
- N 계기판 1.11.0: 설정 → 정보에 USB 디버깅 ON/OFF를 넣었습니다('내 앱'의 USB 디버깅과 같은 순정 요청). N CUSTOM 보라색은 그대로입니다.
- '내 앱' 1.11.0: 버전 이름만 바뀌었습니다(☆ 버튼 → 계기판 포함).
- 설치기 업데이트: Windows·맥 창 설치기에 [업데이트] 단추가 생겼습니다. 새 릴리스가 나오면 창에 단추가 나타나고, 누르면 새 설치기를 받아 해시를 확인한 뒤 엽니다. 콘솔 설치기는 받을지 묻습니다. 새 버전 확인은 날짜 대신 버전 숫자로 비교합니다. Windows 창 설치기의 기록 칸 찌그러짐·질문 창 반복 수정이 들어 있습니다.
- 이 릴리스는 GitHub Actions가 소스에서 빌드했습니다.

확인 범위
- 확인: 태블릿(폰 설치 앱, OTG)으로 v25·v11 실차 설치, ☆ 버튼 → 계기판, N CUSTOM 보라색(차주 확인). 실제 Windows PC에서 가짜 adb로 콘솔·창 설치기 시험.
- 미확인: 1.11.0 실차 설치, 계기판의 USB 디버깅 버튼, Windows 설치기의 실차 연결.
