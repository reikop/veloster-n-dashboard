N 계기판·'내 앱'·모든 설치기 **1.11.3**. 설치기 아이콘을 바꿨습니다.

| 기기 | 받을 파일 | 사용 |
| --- | --- | --- |
| Windows | `vn-installer-windows.zip` | 압축을 풀고 `N계기판설치.cmd` 더블클릭 → 창에서 [설치] (이전 창 설치기는 [업데이트] 단추가 뜹니다) |
| 맥 | `vn-installer-mac.zip` | 압축을 풀고 `N 계기판 설치.app` 실행 |
| 안드로이드 폰·태블릿 | `vn-installer-android.apk` | 설치 후 OTG 어댑터(USB-C → USB-A 암) + A-A 케이블로 차에 연결 |
| 리눅스 | `vn-installer-linux.zip` | `bash install.sh` |

바뀐 점
- 설치기 아이콘: 네온 드라이브의 도트 벨로스터 N이 노을 도로(줄무늬 해·바다·네온 차선) 위에 서 있는 그림으로 통일했습니다. 폰 설치 앱 런처 아이콘, 맥 앱 아이콘, Windows 창 설치기의 창·작업 표시줄 아이콘에 들어갑니다.
- 계기판과 '내 앱'은 버전 이름만 바뀌었습니다(1.11.2와 같은 기능).
- 설치 방법을 저장소 첫 화면(README)에도 정리했습니다.

확인 범위
- 확인: 패키징 시험(Windows ZIP·맥 앱에 아이콘), Windows·맥·리눅스 설치기 시험(GitHub Actions), 태블릿에서 런처 아이콘.
- 미확인: 1.11.x 실차 설치, 새 화면·서킷 랩·카세트 음악 제어, 글꼴 바꾸기의 실차 동작.
