N 계기판·'내 앱'·모든 설치기 **1.11.1**.

| 기기 | 받을 파일 | 사용 |
| --- | --- | --- |
| Windows | `vn-installer-windows.zip` | 압축을 풀고 `N계기판설치.cmd` 더블클릭 → 창에서 [설치] (1.11.0 창 설치기는 [업데이트] 단추가 뜹니다) |
| 맥 | `vn-installer-mac.zip` | 압축을 풀고 `N 계기판 설치.app` 실행 |
| 안드로이드 폰·태블릿 | `vn-installer-android.apk` | 설치 후 OTG 어댑터(USB-C → USB-A 암) + A-A 케이블로 차에 연결 |
| 리눅스 | `vn-installer-linux.zip` | `bash install.sh` |

바뀐 점
- 플로팅 창: 모든 모양에서 최고값(▲)을 보여 줍니다. 세로 캡슐의 부스트 다이얼에도 흰 눈금과 "▲ 1.24"가 다시 나옵니다(i30 PD 포팅 v1.17.4·v1.17.5에서 가져옴).
- 설정 → 글꼴: 순정 글꼴, 동봉한 공개 한글 글꼴 7종(Asta Sans, 나눔고딕, 나눔스퀘어, 나눔스퀘어라운드, 나눔손글씨 펜, 나눔손글씨 붓, 푸어스토리; OFL 1.1), 내비에 이미 있는 글꼴을 보여 주고, 고른 글꼴을 내비 시스템 글꼴로 바꿉니다(파일을 /system/fonts에 복사하고 재시작). 처음 바꾸기 전 설정과 되돌리기 스크립트를 /data/local/tmp/vn-fonts에 남깁니다. [글꼴 안내](https://github.com/reikop/veloster-n-dashboard/blob/main/docs/FONTS.md)
- '내 앱': 버전 이름만 바뀌었습니다.
- 엔진 사운드는 1.11.0과 같습니다.
