N 계기판·'내 앱'·모든 설치기 **1.11.2**. 새 화면 9개를 넣었습니다.

| 기기 | 받을 파일 | 사용 |
| --- | --- | --- |
| Windows | `vn-installer-windows.zip` | 압축을 풀고 `N계기판설치.cmd` 더블클릭 → 창에서 [설치] (이전 창 설치기는 [업데이트] 단추가 뜹니다) |
| 맥 | `vn-installer-mac.zip` | 압축을 풀고 `N 계기판 설치.app` 실행 |
| 안드로이드 폰·태블릿 | `vn-installer-android.apk` | 설치 후 OTG 어댑터(USB-C → USB-A 암) + A-A 케이블로 차에 연결 |
| 리눅스 | `vn-installer-linux.zip` | `bash install.sh` |

새 화면 (탭 줄과 설정 → 화면에서 보이기·숨기기·순서 변경)
- **나이트**: 밤용 최소 화면(어두운 속도 숫자, 얇은 RPM 선, 기어)
- **VFD**: 80년대 청록 디지털 계기판
- **HUD**: 전투기식 초록 HUD(G에 따라 움직이는 사다리, 속도·RPM 테이프)
- **G 원**: 마찰원과 최근 4초 꼬리, 방향별 최고 G
- **워프**: 속도만큼 흐르는 별, 기어=워프 단계, 부스트=에너지
- **드래그**: [측정 준비] → 출발 신호 → 반응 시간, 0-60·0-100 km/h, 201 m
- **카세트**: 재생 중인 곡 라벨, 도는 릴, VU 바늘, 버튼으로 이전·다음·재생/일시정지
- **쇼**: 출력 곡선, 최고값 바늘이 남는 부스트 게이지, G 원
- **서킷**: 국내 6곳(인제, KIC 풀코스·상설, 태백, AMG, 포천) 미니맵과 자동 랩 타이머

설정 → 화면은 20개 화면이 들어가도록 3열로 바뀌었습니다. 새 화면은 i30 PD 포팅(sung9155/i30-pd-dashboard v1.17.7, MIT)에서 가져왔고, 서킷 트랙 선은 © OpenStreetMap 기여자(ODbL 1.0) 자료입니다.
