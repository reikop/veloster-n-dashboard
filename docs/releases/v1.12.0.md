N 계기판·'내 앱'·모든 설치기 **1.12.0**. 새 화면 **내 차**: 3D 벨로스터 N이 깜빡이·라이트·핸들·G에 맞춰 움직입니다.

| 기기 | 받을 파일 | 사용 |
| --- | --- | --- |
| Windows | `vn-installer-windows.zip` | 압축을 풀고 `N계기판설치.cmd` 더블클릭 → 창에서 [설치] (이전 창 설치기는 [업데이트] 단추가 뜹니다) |
| 맥 | `vn-installer-mac.zip` | 압축을 풀고 `N 계기판 설치.app` 실행 |
| 안드로이드 폰·태블릿 | `vn-installer-android.apk` | 설치 후 OTG 어댑터(USB-C → USB-A 암) + A-A 케이블로 차에 연결 |
| 리눅스 | `vn-installer-linux.zip` | `bash install.sh` |

바뀐 점
- 계기판 21번째 화면 **내 차**(설정 → 화면에서 보이기·순서 변경): 3D 벨로스터 N(약 11.6만 폴리곤)을 GLES 2.0으로 그립니다.
  - 좌·우 깜빡이(앞·사이드미러·뒤, 실제 점등 위상), 비상등, 미등, 전조등, 브레이크(보조제동등 포함), 후진등이 차 신호에 맞춰 켜집니다.
  - 핸들각에 맞춰 앞바퀴가 꺾이고, 속도에 맞춰 바퀴가 구르며 빠르면 휠에 모션 블러가 생깁니다.
  - G센서 값에 맞춰 차체가 앞뒤(제동·가속)와 좌우(코너)로 기웁니다.
  - 배경 4종(스튜디오·노을·차고·야간 도로, 360° 파노라마, 차체·바닥에 반사), 출고 6색(슈팅 스타는 무광), 시점 4개, 끌어서 돌리기·두 손가락 확대.
  - 화면을 한 번 누르면 시험 버튼이 나와 램프·핸들을 손으로 켜 볼 수 있습니다(화면을 떠나면 꺼짐).
- 3D 모델: "2022 Hyundai Veloster N" by Ddiaz Design(Sketchfab), CC BY-NC-SA 4.0을 변환한 것입니다. 모델 파일은 MIT가 아니라 같은 CC BY-NC-SA 4.0을 따릅니다([NOTICE](../../NOTICE.md)). 배경 그림은 직접 생성(MIT).

확인 범위
- 확인: 호스트 단위 시험, 안드로이드 에뮬레이터(Android 7.0 arm64, 800×480)에서 화면·시험 버튼·배경·도장·데모 주행 G에 따른 차체 움직임.
- 미확인: 실차(Telechips GPU)에서의 프레임 속도·발열, 실제 차 신호로의 동기화(깜빡이 비트, 핸들·횡가속 좌우 부호, 라이트 스위치 값). 실차에서 느리거나 방향이 반대면 알려 주세요.
