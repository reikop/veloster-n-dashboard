N 계기판·'내 앱'·모든 설치기 **1.11.4**. 설정 → 글꼴의 앱 포함 글꼴을 바꿨습니다.

| 기기 | 받을 파일 | 사용 |
| --- | --- | --- |
| Windows | `vn-installer-windows.zip` | 압축을 풀고 `N계기판설치.cmd` 더블클릭 → 창에서 [설치] (이전 창 설치기는 [업데이트] 단추가 뜹니다) |
| 맥 | `vn-installer-mac.zip` | 압축을 풀고 `N 계기판 설치.app` 실행 |
| 안드로이드 폰·태블릿 | `vn-installer-android.apk` | 설치 후 OTG 어댑터(USB-C → USB-A 암) + A-A 케이블로 차에 연결 |
| 리눅스 | `vn-installer-linux.zip` | `bash install.sh` |

바뀐 점
- 설정 → 글꼴에서 USB 없이 고를 수 있는 앱 포함 글꼴(10종, 모두 현대 한글 11,172자):
  - 고딕: Asta Sans(42dot · Pleos 지정 서체), 프리텐다드, 나눔스퀘어 네오, 부산단디고딕
  - 명조: 부산단디명조
  - 손글씨: 나눔손글씨 펜, 나눔손글씨 붓, 서툰이야기, 부산단디손글씨, 이서윤체
- 나눔고딕·나눔스퀘어·나눔스퀘어라운드는 뺐습니다. 이미 그중 하나를 적용했다면 내비에 남아 있는 파일로 계속 쓰이고, 목록에는 "내비에 설치됨"으로 보입니다.
- 계기판 APK가 약 17.6 MB로 커졌습니다(글꼴 포함). '내 앱'은 버전 이름만 바뀌었습니다.
- 글꼴 라이선스: Asta Sans·프리텐다드·나눔·서툰이야기는 SIL OFL 1.1, 부산단디체는 부산시 전용서체 조건, 이서윤체는 흥국생명 서체 조건입니다. 원문은 [NOTICE](https://github.com/reikop/veloster-n-dashboard/blob/main/NOTICE.md)와 앱 안 `assets/fonts/LICENSE-*.txt`에 있습니다.
