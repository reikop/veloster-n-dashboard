바뀐 점 (i30 PD 포크 [sung9155/i30-pd-dashboard](https://github.com/sung9155/i30-pd-dashboard) v1.17.8~v1.18.0에서 가져옴)
- **화면이 가벼워졌습니다.** 헤드유닛(안드로이드 4.2)은 같은 도형 객체를 다시 쓸 때만 그린 결과를 재사용하는데, 계기판은 7세그먼트 숫자·막대·카드 테두리·운전대 같은 도형을 매 장 새로 만들고 있었습니다. 이제 모양이 같은 도형은 한 번 만든 것을 계속 쓰고, 바늘·호는 0.5° 단위로 맞춰 재사용합니다. 숫자 글자 폭도 한 번 잰 값을 쓰고, 서킷 거리 계산은 멀리 있을 때 간단히 하며, GPS 처리는 화면 스레드에서 분리했습니다. (포크의 i30 PD 실차 측정: 전체 조망 한 장 40 ms → 16~22 ms)
- **엔진 사운드**(설정 → 사운드)
  - 예전(i30 PD v1.16) 합성음으로 돌아갔습니다. 포크에서 차주들이 이 소리를 더 좋아해 되돌린 것을 따랐습니다.
  - 4기통 6종 추가: 2.0 터보 핫해치, 고회전 캠 전환, 수평대향 터보, 랠리 안티랙, 경량 자연흡기, 디젤 터보.
  - **양보**(기본 끔): 내비 안내 음성이 나오면 엔진 소리를 줄이거나 멈춥니다. 통화·벨소리·음성인식 때는 늘 멈춥니다.
  - **속도**(기본 끔): 40~110 km/h에서 바람·노면 소음만큼 엔진 소리를 키웁니다(110 km/h에서 +3 / +6 / +9 dB).
- F1 화면: 수동 게이트의 기어(예: "M7")가 칸을 넘지 않게 줄여서 그립니다.
- **네온 드라이브**: 켜자마자 이미 재생 중인 곡 제목이 나옵니다(전에는 다음 곡으로 넘겨야 나왔습니다).
