N 계기판·'내 앱'·모든 설치기 **1.14.0**. 80년대 디지털 계기판 8종을 담은 새 탭 **레트로**가 생기고, **내 차** 화면에서 문·후드·트렁크가 열리고 미러가 접히며 한국 번호판이 붙었습니다. 내 차 화면과 탭 전환이 가벼워졌습니다.

| 기기 | 받을 파일 | 사용 |
| --- | --- | --- |
| Windows | `vn-installer-windows.zip` | 압축을 풀고 `N계기판설치.cmd` 더블클릭 → 창에서 [설치] (이전 창 설치기는 [업데이트] 단추가 뜹니다) |
| 맥 | `vn-installer-mac.zip` | 압축을 풀고 `N 계기판 설치.app` 실행 |
| 안드로이드 폰·태블릿 | `vn-installer-android.apk` | 설치 후 OTG 어댑터(USB-C → USB-A 암) + A-A 케이블로 차에 연결 |
| 리눅스 | `vn-installer-linux.zip` | `bash install.sh` |

바뀐 점
- **새 탭 레트로**: 80년대 VFD·LED·LCD 계기판 분위기의 화면 8종(트윈 포드, 그린 아크, 곡선 타코, LED 매트릭스, 레인보우, 원근 도로, 앰버 트리플, 트윈 서클). 화면을 누르면 다음 스타일로 넘어가고 고른 스타일은 기억합니다.
  - 켜진 눈금·숫자가 은은하게 빛나고(글로우), 원형 게이지는 직사각형 눈금을 원으로 잘라 둥근 띠로 보입니다.
  - 이 차가 실제로 보내는 값만 씁니다(속도·RPM·기어·수온·유온·전압·부스트·출력·토크·G·공기압·TCS/ESC/ABS 등). 연료 잔량·주행거리·문·라이트 신호는 계기판이 받지 않아 넣지 않았습니다.
  - 방향지시등은 네온 드라이브와 같은 신호로 깜빡입니다(레트로 탭을 보는 동안만 받음).
  - 설정 → 화면 목록이 3열×8로 바뀌었습니다.
- **내 차**
  - 문 3개(운전석, 조수석 앞·뒤)·후드·트렁크가 열리고 사이드미러가 접힙니다. 미러는 앞문과 함께 움직이고, 트렁크에는 스포일러·미등이 같이 붙어 있으며, 후드를 열면 엔진룸이 보입니다. **지금은 화면의 시험 버튼으로만 움직입니다.** 차의 문·트렁크 신호는 아직 해독하지 않았습니다(실차 녹화 후 연결 예정).
  - 앞(그릴 가운데)·뒤(범퍼) 번호판. 내 차 → 번호판에서 번호와 색을 고릅니다: 반사필름(2020~, 태극·KOR 띠), 흰색, 전기차, 영업용, 녹색(구형). 미등을 켜면 뒤 번호판 등 2개가 켜집니다.
  - 더 가볍게 그립니다: 차를 먼저 그려 가려진 배경은 계산하지 않고, 배경·반사 계산을 가벼운 근사식으로 바꾸고, 3D를 화면의 80% 크기로 그려 늘립니다(에뮬레이터 측정 한 장 12.8 → 10.2 ms).
- **가벼워진 계기판**: 내 차·네온 드라이브가 덮고 있을 때 뒤 계기판을 다시 그리지 않고, 탭을 떠나면 3D·네온 드라이브·화면 캐시 메모리를 놓아줍니다(에뮬레이터: 내 차·네온 드라이브를 세 번 오간 뒤 68.5 → 44.9 MB). 그래프·VFD·람다·기록·택시 화면의 그리기 횟수를 줄였습니다.
- **네온 드라이브**: 설정 → 정차 중 움직임을 끄면 정차할 때 차가 각도를 바꾸며 도는 연출과 엔진 떨림이 멈춥니다.
- 번호판 아이디어와 3D 반사 계산 근사 방식은 i30 PD 포크 [sung9155/i30-pd-dashboard](https://github.com/sung9155/i30-pd-dashboard)(MIT)를 참고했습니다.

확인 범위
- 확인: 호스트 단위 시험 34개 프로그램, 계기판·내 앱 APK 빌드, 안드로이드 에뮬레이터(800×480)에서 레트로 8종·내 차 문/후드/트렁크/미러/번호판·네온 드라이브 설정 화면.
- 미확인: 벨로스터 N 실차에서의 화면 속도, 레트로의 깜빡이 표시, 내 차 번호판·문 열림 표시와 GPU 부하, 메모리 해제 뒤 다시 들어갈 때의 동작. 이상하면 알려 주세요.
