# 내 앱 v10: 순정 홈 수정 없이 다시 열기

한국어·영어 선택과 업데이트 변경점은 [언어 안내](LANGUAGES.md)를 참고하세요. 버튼 문구는 선택한 언어에 따라 표시됩니다.

[English](QUICK_ENTRY.md) | **한국어** | [설치 안내](INSTALL.md)

내 앱 v10에는 **화면 가장자리 버튼과 상시 알림**을 선택해서 켜는 기능이 있습니다. 차량별 순정 메뉴 호출 대신 표준 Android 서비스·창을 사용하며 순정 홈을 교체하지 않습니다. ‘범용 경로’는 이 구조를 뜻하며 모든 내비·Android 버전에서 검증됐다는 뜻은 아닙니다.

**v10는 시험 배포본입니다.** 컴파일·서명·PC 생명주기 테스트는 통과했지만 실제 차량에서 버튼 표시와 부팅 알림 전달은 아직 시험하지 않았습니다. 계기판의 차량 데이터 호환성은 별도입니다.

## 최초 설치 — 케이블을 빼기 전에 완료

1. [설치 안내](INSTALL.md)를 따릅니다. 설치 도구는 APK 확인 후 ‘내 앱’을 엽니다. 필요하면 직접 실행합니다.

   ```sh
   adb -s YOUR_DEVICE_SERIAL shell am start -n com.veloster.carplayhub/.HubActivity
   ```

2. ‘내 앱’ 위쪽의 **실행 바로가기 / Quick entry**를 누릅니다.
3. **가장자리 버튼 + 알림 → 저장**을 선택합니다. 기본은 사용 안 함이며 APK 설치만으로 켜지지는 않습니다.
4. 순정 홈으로 돌아갑니다. 화면 가장자리의 작은 **앱** 버튼을 눌러 ‘내 앱’을 다시 열고 **N 계기판**을 실행합니다.
5. 작은 버튼을 끌면 좌우 가장자리에 붙고 상대 높이가 저장됩니다. 필요한 조작부와 후방카메라 화면을 가리지 않는지 실제 화면에서 확인합니다.
6. 화면만으로 다시 열 수 있는 것을 확인한 뒤 PC 연결을 해제합니다. 이후 정차 상태에서 정상 완전 종료·재시동 후에도 버튼이 복원되는지 확인합니다. 이 재시동 확인까지 통과해야 해당 차량에서 설치 완료로 봅니다.

화면의 **설정:** 문구는 선택한 모드이며 순정 화면에 실제로 보인다는 증거는 아닙니다. 아래 실패 문구와 홈 화면을 함께 확인하세요.

## 다른 선택

- **알림만:** 버튼 없이 Android 상시 알림을 눌러 실행합니다. 순정 화면에서 알림 창을 열 수 있을 때 사용합니다.
- **사용 안 함:** 서비스·버튼·알림을 제거하고 이후 부팅 때도 복원하지 않습니다. 다른 실행 경로가 있는지 확인하고 선택하세요.
- 알림의 **바로가기 끄기**도 사용 안 함 설정을 저장합니다.

직접 켜 둔 경우 부팅·앱 업데이트 뒤 **바로가기만 복원**합니다. ‘내 앱’이나 계기판 전체 화면을 자동으로 열지 않습니다. 화면이 꺼지거나 잠기면 버튼을 숨기고 잠금 해제 뒤 돌려놓습니다. 화면을 계속 켜 두는 잠금, 주기적인 부팅 확인, 무선 활성화, 순정 메뉴 변경은 사용하지 않습니다.

## 안 보일 때

| 상황 | 확인 |
| --- | --- |
| 설정이 사용 안 함 | 모드 선택 후 저장. 설치만으로 자동 활성화되지 않음 |
| 버튼 표시 실패, 알림은 유지 | 시스템의 창 표시 거부/실패. 알림을 열 수 있으면 사용하고, ‘다른 앱 위에 표시’ 설정이 있는 기기는 해당 권한 확인 |
| 버튼·알림 모두 접근 불가 | ADB 연결을 유지. 해당 UI에서 이 경로는 사용 불가이므로 오류 확인 후 호환 런처 또는 [정확한 빌드용 순정 메뉴 경로](MENU_ENTRY_ko.md) 사용 |
| 강제 종료 뒤 사라짐 | Android가 종료된 앱의 자동 시작을 막을 수 있음. ‘내 앱’을 직접 다시 열면 저장된 켜짐 설정을 복원 요청 |
| 완전 재부팅 뒤만 사라짐 | ADB로 열어 저장 모드·서비스·알림 상태를 확인. OEM 부팅/서비스 제한 가능성이 있으므로 재설치 반복으로 해결됐다고 보지 않음 |
| 내 앱은 열리지만 계기판 실패 | 계기판 설치와 OEM 라이브러리 호환성을 따로 확인 |

연결 상태에서 확인할 명령:

```sh
adb -s YOUR_DEVICE_SERIAL shell pm path com.veloster.carplayhub
adb -s YOUR_DEVICE_SERIAL shell dumpsys activity services com.veloster.carplayhub
adb -s YOUR_DEVICE_SERIAL shell am start -n com.veloster.carplayhub/.HubActivity
```

공유할 때는 모델·소프트웨어·앱 버전과 관련 오류만 남기고 기기 식별정보를 지웁니다. 개인 캡처 전체는 올리지 마세요. 끌 때는 ‘실행 바로가기 → 사용 안 함’을 사용합니다. 앱 데이터 삭제는 앱 목록 설정까지 지우므로 대체 방법으로 쓰지 않습니다.
